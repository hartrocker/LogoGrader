# LogoGrader
Project for analysing basic characteristics of logo files, such as number of procedures, comments and repeats

Students turn in logo files via Magister. When exporting the results, files are renamed to append the students name before the original name and added to a zip.

The files can be extracted and contain the student names in a fixed syntax because of the renaming. The project is intended as a counter for certain characteristics.

Volume: No of lines, words and characters (excluding comments)

Programming characteristics: Number of comments, type of comments, number of procedures/repeats/variables/colors
